# Andrea Fanelli

Portfolio site. Work is a scrollable 3D stills cloud; Ideas is a daylight playlist of essays. Published Work and Ideas cards open case-style detail pages that share the same layout and UI.

## Run locally

```bash
node scripts/dev-server.mjs
```

The server listens on port 43217 (override with `PORT`).

- Home: http://127.0.0.1:43217/
- Work: http://127.0.0.1:43217/work.html
- A case: http://127.0.0.1:43217/work/glyph-toys.html
- Ideas: http://127.0.0.1:43217/ideas.html
- An essay: http://127.0.0.1:43217/ideas/taste-is-the-only-skill-to-learn.html
